# Roadmap

See the [README](README.md#roadmap) for the product vision (Project Bridge).

## Status

Phase 1 (Local Model Orchestration Engine UI prototype) is complete. The
remaining phases are gated on real users, not on building ahead of need:

1. **Phase 2 — Pi SDK Auth Integration** (in progress path): wire real Pi
   identity into the prototype.
2. **Phase 3 — Decentralized Memory & Data Sync across Pi Nodes.**
3. **Phase 4 — Community-driven Model Marketplace.**

## Explicitly out of scope

- Building phases 3–4 before a real user runs phase 2.
- Cosmetic UI work that doesn't move the prototype toward a real install.
